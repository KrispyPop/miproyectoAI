# miproyectoAI
Esta es la propuesta de proyecto para curso final de AI.

Es una landing page de alta gama diseñada para un artista tatuador. El proyecto combina una estética visualmente impactante con una experiencia de usuario fluida, centrada en la conversión y la atención personalizada a través de un asistente virtual.

Este proyecto nació de una colaboración creativa y técnica entre una humana y modelos de lenguaje (IA), demostrando cómo la tecnología puede potenciar el diseño profesional y el desarrollo frontend.

🎨 El Concepto Visual: "Noir Aesthetic"
Como ilustradora y diseñadora, el objetivo principal fue crear una atmósfera que reflejara la elegancia y la precisión del arte del tatuaje.

Paleta de colores: Negro profundo (#0a0a0a), acentos en oro viejo (#c9a96e) y texturas de ruido sutiles para un acabado orgánico.

Tipografía: Una mezcla de Cinzel Decorative para un toque artístico y Bebas Neue para una estructura moderna y fuerte.

Efectos: Uso de degradados metálicos, animaciones de entrada (fadeUp) y un overlay de grano fotográfico para una experiencia inmersiva.

¿Cómo trabajamos?
Iteración de Diseño: La estructura visual y los estilos CSS fueron refinados conversando con las IAs para lograr efectos complejos como el background-clip: text y el layout responsivo.

Lógica del Chatbot: Se diseñó un sistema de atención al cliente automatizado capaz de simular una conversación real, procesar consultas de precios y derivar a contacto humano directo.

Resolución de Conflictos: Uso de la IA para depurar errores de sintaxis, compatibilidad entre navegadores (vendor prefixes) y optimización de rendimiento.

🛠️ Tecnologías Utilizadas
HTML5 Semántico: Para una estructura sólida y accesible.

CSS3 Moderno: Variables (:root), Flexbox, CSS Grid, animaciones @keyframes y funciones clamp().

JavaScript (Vanilla): Lógica interactiva para el chatbot, manejo de estados de carga y manipulación del DOM.

Google Fonts API: Integración de tipografía especializada.
